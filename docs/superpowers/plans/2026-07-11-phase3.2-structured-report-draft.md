# Phase 3.2 Structured Report Draft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a deterministic, auditable `draft/report_draft.json` from the Phase 3.1 outline and currently eligible Phase 2 evidence.

**Architecture:** Add a focused `report_drafter.py` service that tolerantly reads upstream JSON, revalidates outline-linked sources against current Phase 2 review state, creates one source-derived paragraph block per usable source, builds reverse provenance, validates the artifact, and atomically replaces the output. Integrate the service immediately after report-outline generation and register one new generic file metadata type without changing UI or download routes.

**Tech Stack:** Python 3.11+, Pydantic 2, pathlib, standard-library JSON/tempfile/os/hashlib, pytest, existing local HTTP server and generic download route.

## Global Constraints

- Read only `draft/report_outline.json`, existing Phase 2 research JSON, source-review state, and task metadata.
- Write only `draft/report_draft.json` with `schema: phase3.report_draft.v1` and `status: draft`.
- Preserve Phase 2 formats and paths and preserve the Phase 3.1 outline byte-for-byte.
- Reuse established `source_review_key` and review statuses; do not introduce a second audit parser.
- `approved` blocks are `factual`; `unreviewed` blocks are `candidate` and require review; `rejected` and `needs_followup` never enter body content or `source_index`.
- Do not generate Markdown, Word, PowerPoint, PDF, images, UI, external API calls, browser searches, database state, UUIDs, or random values.
- Rebuild completely and atomically replace on every run; never read the previous report draft as input.
- Keep `main` unchanged, do not create a stable tag, and commit implementation as `phase3.2: generate structured report draft`.

```python
def report_draft_path(workspace: Path) -> Path:
    return workspace / "draft" / "report_draft.json"


def generate_report_draft(record: Any, workspace: Path) -> dict[str, Any]:
    warnings: list[dict[str, Any]] = []
    outline = _read_object(workspace / "draft" / "report_outline.json", warnings)
    sources = _read_object(workspace / "research" / "sources.json", warnings)
    notes = _read_object(workspace / "research" / "research_notes.json", warnings)
    reviews = _read_object(workspace / "research" / "source_review.json", warnings)
    draft = _build_draft(record, outline, sources, notes, reviews, warnings)
    _validate_draft(draft)
    _atomic_write_json(report_draft_path(workspace), draft)
    return draft
```
