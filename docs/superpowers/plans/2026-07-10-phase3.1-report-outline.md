# Phase 3.1 Report Outline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a traceable `draft/report_outline.json` from existing Phase 2 research artifacts and task metadata.

**Architecture:** Add a deterministic `report_planner.py` service that filters sources by human review status, groups eligible evidence into report sections, records provenance, validates the result, and atomically replaces the draft artifact. Integrate it into the existing task workflow after research summarization, and extend the existing file metadata registry with one stable `report_outline` artifact type.

**Tech Stack:** Python 3.11+, Pydantic 2, pathlib, standard-library JSON/tempfile/os, pytest, existing local HTTP server.

## Global Constraints

- Read only existing `research/search_plan.json`, `research/sources.json`, `research/research_notes.json`, `research/source_review.json`, and task metadata.
- Do not query external databases or invoke a model to generate the outline.
- Preserve every Phase 2 file path, schema, and behavior.
- Generate only `draft/report_outline.json`; do not create `report_draft.md`, `slide_plan.json`, or `figure_plan.json`.
- Use `draft/report_outline.json` as the relative path and `report_outline` as the sole file type name.
- Exclude `rejected` and `needs_followup` sources from sections; include follow-up items only in `missing_information`.
- Permit `sections: []` when there are no active `approved` or `unreviewed` sources.
- Do not modify the UI unless the generic file list fails its compatibility test.
- Use the user-requested implementation commit message: `phase3.1: generate report outline from research artifacts`.

```python
REPORT_OUTLINE_SCHEMA_VERSION = "phase3.report_outline.v1"
ELIGIBLE_REVIEW_STATUSES = {"approved", "unreviewed"}


def report_outline_path(workspace: Path) -> Path:
    return workspace / "draft" / "report_outline.json"


def generate_report_outline(record: Any, workspace: Path) -> dict[str, Any]:
    search_plan = _read_required_object(workspace / "research" / "search_plan.json")
    sources = _read_required_object(workspace / "research" / "sources.json")
    research_notes = _read_required_object(workspace / "research" / "research_notes.json")
    source_review = _read_required_object(workspace / "research" / "source_review.json")
    outline = _build_outline(record, search_plan, sources, research_notes, source_review)
    _validate_outline(outline)
    _atomic_write_json(report_outline_path(workspace), outline)
    return outline
```

Implement atomic replacement on Windows by closing the temporary file before `os.replace`:

```python
def _atomic_write_json(path: Path, payload: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    temp_path: Path | None = None
    try:
        with tempfile.NamedTemporaryFile(
            mode="w",
            encoding="utf-8",
            dir=path.parent,
            prefix=f".{path.name}.",
            suffix=".tmp",
            delete=False,
        ) as handle:
            temp_path = Path(handle.name)
            json.dump(payload, handle, ensure_ascii=False, indent=2)
            handle.write("\n")
            handle.flush()
            os.fsync(handle.fileno())
        os.replace(temp_path, path)
    finally:
        if temp_path is not None and temp_path.exists():
            temp_path.unlink()
```
